# iamshashank25.github.io

Personal site of Shashank Verma, Product Manager at PollPe.

**Live:** https://iamshashank25.github.io

| File | What it does |
|---|---|
| `index.html` | All the text and sections |
| `style.css` | Colours, fonts, layout (colours are at the top) |
| `images/` | Photos |

## Making a change

1. Create a branch, edit, commit.
2. Open a Pull Request on GitHub and look at the changes.
3. Merge it. GitHub Pages updates the live site in a minute or two.
